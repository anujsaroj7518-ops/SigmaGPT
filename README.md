# SigmaGPT

A ChatGPT-style AI chat application built with React (frontend) and Node.js + Express + MongoDB (backend). SigmaGPT lets users chat with an AI, manage multiple conversation threads, and interact with messages just like modern AI chat apps.

## Features

- 💬 **Real-time AI chat** with typewriter-style response animation
- 🗂️ **Multiple chat threads** — create, switch between, and delete conversations
- 📝 **Markdown rendering** for AI responses, including code blocks with syntax highlighting
- 📋 **Message actions** — copy, share, and edit your messages
- ⬇️ **Scroll-to-bottom button** that appears when scrolled up in a long conversation
- ⚙️ **Settings** — update profile info and preferences
- ⬆️ **Upgrade Plan** — free / pro / enterprise plan tiers
- 🚪 **Logout** — secure session termination
- 🎨 Clean, dark-themed UI inspired by ChatGPT

## Tech Stack

**Frontend**
- React (Vite)
- React Markdown + remark-gfm + rehype-highlight
- Font Awesome icons
- CSS (custom, no framework)

**Backend**
- Node.js + Express
- MongoDB + Mongoose
- JWT-based authentication
